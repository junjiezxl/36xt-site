# 英国 Asda Mobile 保号卡：规则、费用与待验证点

> 📅 **本文核实日期：2026-11-11**。保号规则、漫游资费、eSIM 说明均以据官方帮助中心与条款整理；社区实测说法单独标注。**官方口径前后不一致的地方已标「说法不一」，无法核实的标「待验证」**，下单前请以 Asda Mobile 当时页面为准。

最近不少人在讨论把 **Asda Mobile** 当作 giffgaff 之外的另一张英国 `+44` 保号卡。它是英国连锁超市 Asda 旗下的虚拟运营商，据官方条款跑在 **Vodafone** 网络上，Pay As You Go（按量付费）模式没有合约、不查信用。

先说结论：**它可以作为「备选 / 第二张英国号」研究，但不建议新手当唯一主力保号卡。** 原因是保号规则官方自己写法就有出入，eSIM 新开渠道和内地漫游费率也有待验证点。想要稳妥的低成本主力卡，仍然优先看 [菲律宾 DITO](/sim/ph-dito) 和 [香港 Club SIM](/sim/hk-clubsim)。

## 一、核心规则一览

::: warning 保号规则：官方两处写法不一致，按最严格的来
据官方帮助中心「充值」页面，同一页上有两种说法：

1. **「每 180 天要有一次计费的通话或短信」**，否则号码进入受限状态（不能拨出，只能接听）；
2. **「每 180 天内要充值或购买一次套餐」**，否则账户受限，只能接收来电和短信。

两种说法都写着：受限后**再过 90 天（即累计约 270 天）没处理，号码会被注销、余额清零，且无法找回**。官方条款里则只写了「连续 270 天没有计费通话或短信就停用并注销号码」。

**稳妥做法：每 150 天左右同时做两件事——充一次最低额话费，再发一条计费短信。** 这样无论按哪种口径都不会掉号。
:::

| 项目 | 规则 / 费用 | 说明 |
| :--- | :--- | :--- |
| **网络** | Vodafone（据官方条款） | 有第三方整理称也接入 Three 网络，**待验证** |
| **月租** | Pay As You Go 无月租 | 包月套餐（Talk & Text 约 £4/月起）保号用不上，别误买 |

## 二、eSIM 现状：说法不一

- **据官方 eSIM 页面**：eSIM 目前面向 **SIM-only 合约套餐**，以及「已经是 Asda 用户，可免费转 eSIM」；激活方式是在网上账户里拿二维码扫码安装。官方还说明 eSIM 暂不支持平板和手表。
- **社区实测**：有用户近期反馈直接申请到了 Asda eSIM，号码也比较「干净」，没遇到诈骗电话；但这属于个人体验，**新用户能否直接以 Pay As You Go 方式开 eSIM，待验证**。
- **第三方资费站**说法也不统一，有的写「不支持 eSIM」，有的写「结账时可选 eSIM」。

**建议：** 想走 eSIM，就先按官方路径拿到实体卡并激活，再在账户里申请免费转 eSIM；不要花钱买来路不明的「成品 Asda eSIM」。

## 三、办卡与激活思路（据官方流程整理）

1. **拿卡**：官方网站可免费申请 SIM，Asda 门店也有 50 便士卡 / 预充值卡。官方免费寄卡**是否支持寄到中国大陆地址，待验证**；请在英国的朋友代领、或国内电商购买未激活空白卡也是常见做法（只买未激活的空白卡，激活和账户都在你自己手里）。
2. **激活**：据官方条款，卡片在**第一次产生计费行为**（打电话、发短信或用流量）时激活。所以首次充值后，需要发一条计费短信或打一个计费电话，号码才算真正启用。
3. **充值**：在官方网站或 App 用 Visa / Mastercard 充值话费余额（Pay As You Go Top-up）。**不要选包月套餐**，保号只需要余额。
4. **开 Wi‑Fi Calling（可选）**：激活满 7 天后，在手机设置里打开 Wi‑Fi 通话。

## 四、激活后必做设置

::: warning 三件套
1. **立刻关闭这张卡的「数据漫游」**：按官方漫游价，流量按 MB 计费，后台跑几分钟就可能把余额扣光。
2. **关闭语音信箱 / 呼叫转移**：避免陌生来电转入信箱产生漫游接听费。
3. **日历提醒每 150 天一次**：到点先充一次最低额，再发一条计费短信，然后在账户里确认余额变化。
:::

## 五、和 giffgaff 怎么选？

| 对比项 | Asda Mobile | giffgaff |
| :--- | :--- | :--- |
| 网络 | Vodafone | O2 |
| 保号规则 | 180 天（官方写法不一，按「充值 + 计费短信」保守操作） | 180 天内有一次符合规则的活动（社区口径常见为发短信） |
| 注销期限 | 受限后再过约 90 天注销（累计约 270 天） | 以官方帮助中心为准 |
| eSIM | 官方面向合约用户和老用户转换，新开**待验证** | 可在 App 内申请 / 转 eSIM |
| 本站态度 | 备选第二张英国号，需自己承担规则变动风险 | 老号可养，新用户不建议当唯一主号（见 [giffgaff 风险预警](/sim/uk-giffgaff)） |

::: danger 风险提示
- Asda 与 giffgaff 同属**英国免实名虚拟运营商**，长期在英国境外漫游、完全不在英国本土使用的号码，同样可能被运营商的反欺诈规则命中。官方条款也写明，运营商可以在其认为违反使用规则时停用或终止服务。
- **不要把银行、券商等重要账户只绑这一张号**，至少再配一张实名的主力保号卡做备份。
:::
