## 科普：国行手机没有 eSIM 功能，能用海外 eSIM 吗？

很多朋友手握国行手机，但又眼馋海外丰富的 eSIM 资源（如 Club SIM、Tello、海外旅游流量 eSIM）。目前圈内成熟方案是 **「实体可擦写 eSIM 卡（如 5ber / Estk / 9esim 等写卡器卡片）」**：

- **原理**：它是一张长得和普通国内电话卡一模一样的实体纳米芯片卡，内置了标准 eUICC 芯片。
- **用法**：把这张空芯片插进国行安卓手机（或通过读卡器插电脑/苹果手机），用配套 App 扫描海外运营商给你的 eSIM 二维码，把 eSIM 配置文件“烧录”进这张实体卡里。
- **效果**：烧录完成后，它就变成了一张真正的实体电话卡，插进任何国行 iPhone 或安卓手机都能正常出信号、收短信，一张卡内最多可存储 8~15 个不同国家的号码随时切换！

::: tip 漫游防扣费必做设置！
无论你使用哪张海外手机卡，在插入手机激活出信号后，**第一时间进入手机「设置 → 蜂窝网络 / 移动网络」关闭该副卡的「数据漫游（Data Roaming）」开关！**
收短信在漫游状态下是完全免费的，但一旦误开流量漫游跑后台更新，账户余额几分钟就会被扣光。
:::
