# 出海工具全家桶：从证件到 eSIM 的一条龙路线图

> 📅 **本文整理日期：2026-11-09**。本文是「导航页」，不重复展开各卡种细节，只告诉你整条链路怎么串、先做什么后做什么，并跳转到站内已有教程。费率与政策以各专题页为准。

很多人做出海配置，最容易踩的坑不是「办不成」，而是**顺序乱、工具散、缺一环卡死整条链**。

本页把 36星途站内的核心工具串成一条可执行路线：

```
证件 → 地址证明 → 保号手机卡 / eSIM → 港卡 / 数字账户 → 券商（可选）→ 出入金与长期持有
```

## 五步通关：每一环解决什么问题

### 第 1 步｜证件：你的「国际身份证」

- **因私普通护照**：多数远程账户、eSIM 实名、券商开户的基础证件。
- **港澳通行证 + 有效签注**：人要去香港 / 澳门开户时必带。
- **有效期红线**：护照与通行证剩余有效期建议大于 6 个月。

→ 展开阅读：[第 1 步：核心证件准备](/roadmap/documents)

### 第 2 步｜地址证明：银行最爱卡人的那一关

合格地址证明通常要同时满足：权威机构出具、近 3 个月、姓名一致、完整门牌。

最稳零成本方案：国内银行**带地址的信用卡月结单 PDF**。

→ 展开阅读：[第 2 步：地址证明](/roadmap/address-proof)

::: danger 严禁伪造与篡改
不要用修图软件改账单地址、日期或姓名。金融机构文档核验会抓篡改痕迹，轻则拒批，重则永久拉黑身份。真实材料不够时，走正规翻译件或银行英文证明，不要「自己造」。
:::

### 第 3 步｜保号手机卡 / eSIM：通信地基

目标不是「出国上网」，而是：**长期保住一个能稳定收 OTP 验证码的号码**，并尽量控制年均成本。

| 场景 | 更合适的方向 |
| :--- | :--- |
| 极致低成本 + 护照实名抗封 | 菲律宾 DITO 等（详见对比页） |
| 开港卡 / 港区服务，要 `+852` | 香港 Club SIM |
| 纯出国流量、不需要号码 | 红茶移动等纯数据 eSIM（不能当保号主号） |
| 老号维护 | 按各运营商规则保号，留意封卡风险 |

→ 展开阅读：[选卡总览](/sim/) · [eSIM / 保号卡横向对比](/sim/esim-compare) · [Club SIM](/sim/hk-clubsim) · [DITO](/sim/ph-dito) · [Giffgaff](/sim/uk-giffgaff)

### 第 4 步｜港卡与数字账户：资金落脚点

按能不能去香港，分两条主路：

- **能去香港一天**：优先考虑中银香港（跨境省钱）+ 汇丰 One（综合中枢）+ 众安 ZA（数字银行补位）。组合打法见 [香港三卡怎么配](/bank/hk-three-card)。
- **暂时去不了**：先看 [远程护照直开账户](/bank/remote-accounts)，把基础境外账户跑通，以后再补港卡。

众安邀请码：**`CJV889`**（开户时填写，事后不能补）。  
若顺路去澳门，蚂蚁银行（澳门）邀请码：**`LPJL4ERW`**。

→ 展开阅读：[账户总览](/bank/) · [赴港一日通关](/bank/hk-walk-in) · [众安教程](/bank/za-bank) · [澳门蚂蚁教程](/bank/ant-bank-macau) · [汇丰内地预申请](/bank/hk-hsbc-remote)

### 第 5 步｜券商与出入金：把「账户」变成「可用系统」

- **券商**：不是人人都要开。若你确有境外投资需求，先读清材料门槛与税务合规边界，再决定是否申请。详见 [盈透 IBKR 开户 + 海外地址证明合规指南](/broker/ibkr-guide)。
- **出入金**：始终坚持「真实用途、如实申报、同名路径、留存凭证」。个人年度购汇便利化额度为等值 **5 万美元**（按自然年），且**不得用于境外证券投资等未开放资本项目**——这是硬规则，不是技巧。详见 [跨境资金闭环（合规版）](/roadmap/compliant-fund-loop)。

## 推荐工具组合（按目标选，不要贪多）

### 组合 A｜最小可用（预算紧、先通基础）

1. 护照 + 带地址信用卡账单  
2. 一张低成本保号 eSIM（优先看 [横向对比](/sim/esim-compare)）  
3. 一张远程数字账户或下次赴港补一张港卡  
4. 首笔同名小额入金激活 + 日历保号提醒  

### 组合 B｜赴港一天标准配置（最常用）

1. 证件 + 地址证明 + `+852` 保号号（Club SIM 等）  
2. 中银香港（跨境）+ 汇丰 One（中枢）+ 众安 ZA（数字补位，邀请码 `CJV889`）  
3. 首笔入金与养户习惯  
4. （可选）澳门蚂蚁作利率/备用仓，邀请码 `LPJL4ERW`

### 组合 C｜完整「工具全家桶」（有明确境外投资与长期持有需求）

在组合 B 基础上增加：

1. 合规前提下的券商账户（材料真实，绝不伪造）  
2. 清晰的资金进出与税务记录习惯  
3. 主号 + 备用号双通信，降低单点故障

## 自查清单（做完打勾）

- [ ] 护照 / 通行证有效期 > 6 个月  
- [ ] 近 3 个月带地址账单 PDF 已导出  
- [ ] 至少 1 张海外保号号已激活，并设好续期提醒  
- [ ] 至少 1 个境外银行 / 数字账户已开立  
- [ ] 首笔同名入金已完成，账户非长期零余额  
- [ ] 了解个人购汇「六不得」与年度便利化额度边界  
- [ ] （如开券商）材料真实，已阅读合规指南
