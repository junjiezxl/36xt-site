# 36星途：新手从 0 到 1 出海完整路线图

很多第一次接触海外服务（如海淘订阅、留学缴费、商旅出行、港美股合规理财或跨境收付款）的朋友，最容易踩的两个大坑是：

1. **顺序搞反**：还没办好海外手机号和地址证明，就急着提交银行开户申请，结果因频繁更换绑定号码或材料不全被秒拒，留下拒批记录。
2. **花冤枉钱找中介**：把本来 **0 元开户费** 的香港银行卡或免费领取的英国手机卡，花几千块钱找所谓“包过渠道”代办，不仅泄露全套隐私，还可能因假材料被银行永久拉黑。

本路线图把所有准备工作拆解为 **6 个标准步骤**，按顺序推进即可零中介费完成配置。

## 为什么必须遵守「先卡后户」原则？

::: warning 核心避坑：不要用 +86 手机号长期绑海外银行主账户（除非官方明确支持且稳定）
1. **短信拦截问题**：部分海外银行或国际平台的跨国 OTP 验证码短信，在经过国际网关下发至国内运营商时，偶尔会被防骚扰策略默认拦截，导致登录或转账卡死。
2. **风控敏感度**：海外银行对「开户后短期内修改注册手机号/国籍地区」极为敏感，往往要求打跨国英语客服电话甚至寄送纸质表格核身。一开始就用长期持有的海外保号卡注册，一劳永逸。
:::
