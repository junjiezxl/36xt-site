# 海外银行卡与数字账户：总览与开户门槛对比

对于中国大陆居民而言，开立境外账户的核心原则只有八个字：**合规持牌、零管理费**。不要去碰任何来路不明的小岛野鸡平台，也无需花几千块找中介搞所谓“VIP 见证存款几十万包过”——普通人准备好证件，自己申请完全 0 手续费。

## 两条路线，按自身条件对号入座

### 路线 A：近期能抽 1 天时间去香港（最稳妥、一步到位！）
如果你在珠三角，或者趁周末/节假日顺路去香港旅游一天：
- 强烈建议直接走 **[赴港开户一日通关攻略（汇丰 One + 中银香港 + 众安 ZA）](./hk-walk-in)**。
- 早上过关连上香港漫游网络，吃早餐的功夫在手机上用 15 分钟把线上申请点完，再去预约网点核身，一天之内零成本拿下 **2 家顶级传统发钞行 + 1 家虚拟银行**，未来十年几乎不再需要折腾其他卡。

### 路线 B：暂不方便去香港（内地足不出户远程办理）
如果你住在北方或内陆省份，近期没有通行证出境计划：
- 可以先阅读 **[远程护照直开海外账户对比](./remote-accounts)**，用护照 + 地址证明线上开通 **英国 iFAST Global Bank** 等合规远程账户，先把境外多币种账户跑通，等将来顺路去香港旅游时再补齐港卡。

::: warning 防骗警钟：警惕「付费远程代开港卡 / 新加坡卡」陷阱！
凡是在社交媒体声称“交 ¥2,000~¥5,000 不用去香港、不用存款就能远程包开汇丰/中银/OCBC”的黑中介，无一例外是利用 PS 伪造境外工作签证、伪造定位或内部违规通道。此类账户一旦在半年后的银行合规回查中被揪出，不仅**直接封户冻结资金**，你的护照信息还会进入银行业共享反欺诈黑名单（CIFAS / 香港银行同业记录），得不偿失！
:::
