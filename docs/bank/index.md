## 二、办卡的完整流程（逐环节拆解）

### （1）定机票、定酒店
- 即使是纯线上办虚拟银行卡，也要求**本人身处香港境内，连接香港当地酒店或公共场所的 Wi-Fi 并开启定位**才能提交。
- **网点与酒店选择技巧**：香港到处都是中国银行（香港）网点，避开尖沙咀、旺角、罗湖口岸等游客爆满网点，可以选择**元朗、屯门、沙田或港岛非核心商业区**的酒店（例如元朗附近的酒店性价比高，距离中银香港元朗青山道分行坐公交仅半小时），第二天一早去酒店附近的中银香港网点排队即可。

### （2）过海关、进香港（通关小票千万别丢！）
- 若飞抵深圳宝安机场，距离机场最近的口岸是**深圳湾口岸**（打车或地铁直达）。
- **重点动作 ①**：刷港澳通行证过香港海关闸机时，机器会吐出一张白色的**通关小票（入境标签）**，<span class="ht-hl">务必拿好夹在通行证里，千万不要弄丢</span>，周一早上线下网点办中银香港必看！
- **重点动作 ②**：过关连上网络后，打开微信/支付宝搜索**「移民局 12367」小程序**，下载包含本次入境香港记录的**《出入境记录》PDF 文件**保存在手机里，线上申请银行时直接上传（提前导出，避免在银行 App 开户中途频繁切屏影响审核）。

### （3）线上申请众安银行（ZA Bank，必开首选！）

### （4）线上申请汇丰银行（HSBC One，按需选开）
- **先看是否适合你**：2026 年 1 月 1 日起新开的汇丰 One（非香港身份证），若日常平均结余低于 **1 万港币**会收取 **100 港币/月**管理费。
  - 如果你愿意长期在汇丰放 1 万港币以上（买定存或货币基金也计入）：可以在酒店连 Wi-Fi 打开 **HSBC HK** App → 选择「我没有任何账户」→「我没有香港身份证」→「汇丰 One」→ 开户原因选**「打算在香港储蓄投资」**→ NFC 扫描港澳通行证芯片 → 上传出入境记录 PDF → 填写中英文地址与身份证号（税号）完成秒开（也可先在内地预申请再到港激活，详见 <a href="/bank/hk-hsbc-remote">《汇丰 One 内地预申请+赴港激活》</a>）。
  - 如果你不想压 1 万港币资金：**直接跳过汇丰**，接着开下面的恒生、众安等银行即可。

### （5）线上申请恒生银行、大象银行（原天星）、蚂蚁银行（香港）
趁周日晚上在酒店连着香港 Wi-Fi，顺手把以下三家线上可申的银行一并点完（全部支持身份证号作为税务编号；富融银行 Fusion Bank 对内地居民已基本收紧，需企业邮箱或职员推荐验证码，不建议安排）：
1. **恒生银行（Hang Seng HK）**：下载恒生 Mobile App →「手机开户」→「我要开立恒生综合户口」→ 选**优进理财**（据官方不收低额结存服务费）→ 拍通行证 + NFC 读芯片 + 自拍 → 上传出入境记录 → 填写住址（城市一栏要填）与工作信息提交。**也可以出发前在内地先提交，到港后 90 天内在 App 上传出入境记录完成开户**，详见 <a href="/bank/hangseng-remote">《恒生内地预申请 + 赴港激活》</a>。
2. **大象银行 EleBank（原天星银行 Airstar Bank，不是富融）**：据官方公告，天星银行 2026 年 4 月改名「象象银行」，8 月中文名再改为「大象银行」，英文 EleBank 不变，老账户不受影响；第三方转账时仍可能显示旧名。下载大象银行 App → 扫描港澳通行证和身份证、刷脸 → 税务编号填内地身份证号 → 上传出入境记录 → 提交开户。
   - ⚠️ **待验证/说法不一**：近期有多名用户反馈，App 对内地**新**客户要求上传约 **10 万港币等值的境外资产证明**（内地存款与内地券商据称不认），没有就开不了；已开户的老客户不受影响。官方未见公开说明，开户前以 App 内要求为准，没有境外资产的话把它放到最后、优先开众安和蚂蚁（香港）。
3. **蚂蚁银行（香港）（Ant Bank HK）**：下载蚂蚁银行（香港）App → 选择账户类型 → 填写个人信息 → 申请投资账户并上传出入境证明。

### （6）周一早上：线下网点申请中国银行（香港）当场拿卡
<ul class="ht-list">
  <li><strong>早起排队稳拿号：</strong>即使没提前在微信预约上，只要在<strong>周一早上 8:00 前（比如 7:30）</strong>到达中银香港网点门口排队（9:00 准时开门），基本都能拿到现场号。</li>
  <li><strong>出示「开卡四件套」：</strong>进门客户经理会核验你的 <span class="ht-hl">身份证、港澳通行证、通关小票、地址证明</span>，核验无误后给你取号，并引导你在 BOCHK App 内预填资料。</li>
  <li><strong>避坑关键点（账户等级选择）：</strong>客户经理可能会引导勾选「智盈理财」（需维持 20 万港币，不达标 3 个月后才降级）。建议<strong>直接勾选「自在理财」</strong>，不要勾「智盈理财」（须维持 20 万港币）。自在理财也不是无条件免费：据官方《自在理财》服务概览，该项服务在综合理财总值达 <strong>1 万港币</strong>或以上时月费全免，低于则每月 <strong>60 港币</strong>。这只是「自在理财」的服务月费，不是中银香港所有账户类型的统一收费。18 岁以下，以及合资格全日制学生（香港、内地及海外大学或专上院校）在学期间和毕业后首 3 年，可在分行选用或提升至自在理财时出示有效学生证明申请豁免。开户本身通常不必先存 1 万；存量客户是否已全部按此扣费，以账户实际扣费为准。若长期不打算放够 1 万，就要按官方这项收费评估月费。</li>
  <li><strong>地址证明铁律：</strong>地址证明强烈建议用<strong>带完整家庭住宅地址 + 加盖银行公章的信用卡账单</strong>（不要写便利店或快递驿站地址，详见 <a href="/roadmap/address-proof">《零成本地址证明全攻略》</a>）。</li>
  <li><strong>客户经理面谈 4 连问标准答案：</strong>
    <br/>① <em>“开卡用途是什么？”</em> → 答：<strong>“港美股投资 / 储蓄理财”</strong>（大方自然回答）。
    <br/>② <em>“之前有投资经验吗？”</em> → 答：<strong>“有，炒股好几年了，手机里有 A 股/基金账户可以展示。”</strong>
    <br/>③ <em>“公司名称、职位、年收入多少？”</em> → 按实际情况如实回答即可（从容作答）。
    <br/>④ <em>“开卡同时开通中银港股账户可以吗？”</em> → 答：<strong>“好的没问题”</strong>（开通后不强制使用，平时用低佣券商即可）。

</ul>

### 十一、八条最容易踩坑的注意事项
1. **手机必须支持 NFC 功能**：线上开汇丰、中银扫描港澳通行证芯片全靠 NFC（读取时记得摘下厚手机壳）。
2. **手机必须开通国际漫游**：到港后收不到短信验证码，一张卡都办不了。
3. **强烈建议多带一部备用手机**：防止主力手机摄像头微距无法对焦识别港澳通行证。
4. **材料宁多勿少**：四件套 + 社保/个税截图准备好，去一趟香港不容易，确保一次过。
5. **记牢线上注册的所有用户名、密码、安全问题与参考编号**：好记性不如烂笔头，当场备忘录记好。
6. **线上开户过程中不要频繁切屏**：所以《出入境记录》PDF 和英文地址一定要在打开银行 App 之前就准备好。
7. **仔细核对姓名拼音与英文地址**：确保没有拼写错误。
8. **提前查好香港天气**：避开八号风球或黑色暴雨警告日（台风天香港银行全线停业）。
