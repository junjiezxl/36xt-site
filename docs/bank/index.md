## 二、办卡的完整流程（逐环节拆解）

### （1）定机票、定酒店
- 即使是纯线上办虚拟银行卡，也要求**本人身处香港境内，连接香港当地酒店或公共场所的 Wi-Fi 并开启定位**才能提交。
- **网点与酒店选择技巧**：香港到处都是中国银行（香港）网点，避开尖沙咀、旺角、罗湖口岸等游客爆满网点，可以选择**元朗、屯门、沙田或港岛非核心商业区**的酒店（例如元朗附近的酒店性价比高，距离中银香港元朗青山道分行坐公交仅半小时），第二天一早去酒店附近的中银香港网点排队即可。

### （2）过海关、进香港（通关小票千万别丢！）
- 若飞抵深圳宝安机场，距离机场最近的口岸是**深圳湾口岸**（打车或地铁直达）。
- **重点动作 ①**：刷港澳通行证过香港海关闸机时，机器会吐出一张白色的**通关小票（入境标签）**，<span class="ht-hl">务必拿好夹在通行证里，千万不要弄丢</span>，周一早上线下网点办中银香港必看！
- **重点动作 ②**：过关连上网络后，打开微信/支付宝搜索**「移民局 12367」小程序**，下载包含本次入境香港记录的**《出入境记录》PDF 文件**保存在手机里，线上申请银行时直接上传（提前导出，避免在银行 App 开户中途频繁切屏影响审核）。

### （3）线上申请众安银行（ZA Bank，必开首选！）
到达酒店连上香港 Wi-Fi 后，第一个开通**众安银行（ZA Bank）**——香港排名第一的持牌虚拟银行，App 交互体验跟内地主流软件一样丝滑，**0 账户管理费、无最低存款要求**。

### （4）线上申请汇丰银行（HSBC One，按需选开）
- **先看是否适合你**：2026 年 1 月 1 日起新开的汇丰 One（非香港身份证），若日常平均结余低于 **1 万港币**会收取 **100 港币/月**管理费。
  - 如果你愿意长期在汇丰放 1 万港币以上（买定存或货币基金也计入）：可以在酒店连 Wi-Fi 打开 **HSBC HK** App → 选择「我没有任何账户」→「我没有香港身份证」→「汇丰 One」→ 开户原因选**「打算在香港储蓄投资」**→ NFC 扫描港澳通行证芯片 → 上传出入境记录 PDF → 填写中英文地址与身份证号（税号）完成秒开（也可先在内地预申请再到港激活，详见 <a href="/bank/hk-hsbc-remote">《汇丰 One 内地预申请+赴港激活》</a>）。
  - 如果你不想压 1 万港币资金：**直接跳过汇丰**，接着开下面的免费银行即可！

### （5）线上申请恒生银行、大象银行（富融）、蚂蚁银行（香港）
趁周日晚上在酒店连着香港 Wi-Fi，顺手把以下三家线上可申的银行一并点完（全部支持身份证号作为税务编号）：
1. **恒生银行（Hang Seng HK）**：下载恒生香港 App → 线上开户 → 选优选理财 → 上传出入境记录 → 开户原因选【在香港储蓄/投资】→ 填写住址与工作信息提交。
2. **大象银行（原富融银行 Fusion Bank）**：下载大象银行 App → 确认身份信息 → 税务编号填内地身份证号 → 提交开户。
3. **蚂蚁银行（香港）（Ant Bank HK）**：下载蚂蚁银行（香港）App → 选择账户类型 → 填写个人信息 → 申请投资账户并上传出入境证明。

### 十一、八条最容易踩坑的注意事项
1. **手机必须支持 NFC 功能**：线上开汇丰、中银扫描港澳通行证芯片全靠 NFC（读取时记得摘下厚手机壳）。
2. **手机必须开通国际漫游**：到港后收不到短信验证码，一张卡都办不了。
3. **强烈建议多带一部备用手机**：防止主力手机摄像头微距无法对焦识别港澳通行证。
4. **材料宁多勿少**：四件套 + 社保/个税截图准备好，去一趟香港不容易，确保一次过。
5. **记牢线上注册的所有用户名、密码、安全问题与参考编号**：好记性不如烂笔头，当场备忘录记好。
6. **线上开户过程中不要频繁切屏**：所以《出入境记录》PDF 和英文地址一定要在打开银行 App 之前就准备好。
7. **仔细核对姓名拼音与英文地址**：确保没有拼写错误。
8. **提前查好香港天气**：避开八号风球或黑色暴雨警告日（台风天香港银行全线停业）。

### 十二、总结与快速跳转
- **中国银行（香港）**：必办传统发钞行，勾选「自在理财」**0 管理费**，跟内地中行同名互转最省钱。
- **众安银行（ZA Bank）**：必办线上虚拟银行，丝滑好用 **0 管理费**（邀请码 **`CJV889`**，记得在港同步开通投资户）。
- **恒生 / 大象 / 蚂蚁（香港 / 澳门）**：趁在港澳连 Wi-Fi 顺手全开，多几张卡互为备份更踏实。
