## 一、 先回答三个最常见的问题

| 问题 | 结论 | 依据 |
| :--- | :--- | :--- |
| 内地身份能开吗？ | **能**。持内地身份证 + 港澳通行证，以「访港旅客」身份在 App 内开户 | 官网推荐活动条款：合资格客户包括「香港居民及访港旅客」 |
| 必须人在香港吗？ | **必须**。需在香港境内提交申请，App 会检测定位，还要上传含本次入境记录的出入境记录 | 官网条款写明「于香港境内」开户；多帖实测 |
| 要不要去柜台？ | **不用**。全程 App 线上办理，无实体网点 | 众安是香港持牌虚拟银行 |

::: warning 在内地「远程开众安」= 不可能
任何声称「不用来香港也能开众安」的代开、租号服务，都不是官方途径，账户随时可能被冻结，资金也有风险。
:::

## 二、 开户前准备清单

| 材料 | 要求 | 备注 |
| :--- | :--- | :--- |
| 内地二代身份证 | 原件，开户当天起剩余有效期 **≥ 30 天** | 网友实测 / 第三方整理 |
| 港澳通行证 | 原件，含有效赴港签注 | 入境后保留好入境小白条 |
| 内地手机号 | 在香港能**正常收短信**（开通国际漫游） | 用来收验证码 |
| 同名内地借记卡 | 预留手机号须与开户手机号**一致** | 部分用户被要求做银行卡验证 |
| 出入境记录 PDF | 必须**包含本次入境**的记录 | 在「移民局 12367」App / 小程序申请，下载 PDF |
| 香港居住地址 | 填酒店地址即可 | 不需要地址证明文件 |

::: warning 关于出入境记录
- 一定要在**入境香港之后**再申请，否则记录里没有本次入境，会被要求重新提交；
- 有网友引用众安 FAQ 称：开户后需在 **2 天内**补交出入境记录 PDF，保险起见建议**开户当天就在香港上传**。
:::

## 三、 开户步骤（约 10–20 分钟）

1. **入境香港后**关闭 VPN / 代理，下载「ZA Bank」App（App Store 或 Google Play；安卓也可以去官网下载）。
2. 用内地手机号注册，接收短信验证码。
3. 选择证件类型：**内地居民身份证**，按提示拍摄身份证正反面、港澳通行证。
4. 人脸识别（光线充足，不要戴帽子或眼镜）。
5. 填写个人资料：职业、收入、开户用途（如实填写，如「储蓄 / 投资 / 日常消费」）、税务居民身份（中国内地，税号即身份证号）、香港临时地址（酒店）。
6. 🎁 **填写推荐码：在「推荐码 / 邀请码」一栏输入 `CJV889`**
   ::: tip 这一步别跳过
   推荐码 **`CJV889`** 只能在这一步填，**开户后无法补填**。填完核对一遍再提交。
   :::
7. 上传包含本次入境的**出入境记录 PDF**；如果被要求，就绑定同名内地借记卡做验证。
8. 提交申请。网友实测一般 **2–3 个工作日**内出结果，审批时最好人还在香港，方便接电话或补件。
9. 审批通过后，设置交易密码，开通 FPS（转数快）。如需要，可申请 ZA Card（万事达借记卡）。

## 四、 入金：第一笔钱怎么进

| 方式 | 说明 |
| :--- | :--- |
| 港币现金 / 本人其他港卡 FPS 转入 | 最省事；同名转入最安全 |
| 内地银行跨境汇款 | 按外汇管理规定如实申报用途，收款人写本人英文名，收款行 SWIFT 以 App 内显示为准 |
| 他人转入 | 不建议。非同名、来源不明的资金是风控高发区 |

::: tip 想拿开户奖励 ②（19.9% 加息券）
必须在**开户后 14 天内**，**单笔**存入 ≥ HK$1,000「新资金」，详见下一节。
:::

**2026-11-01 起众安的收费调整（官网通告）：**
- **SWIFT 汇出**：每笔 **HK$70**；
- **账户余额不足导致扣款失败**：当月 ≥ 10 次，收 **HK$120**；
- **ZA Perks 会员可豁免**：Lv1（总资产 HK$1 万–50 万）每月前 3 笔 SWIFT 汇出免费；Lv2（≥ HK$50 万）全部免费。

更多入金细节见：[境外账户首笔入金与激活避坑](./first-deposit)。

## 六、 风控避坑

1. **全程本人、本机、在港操作**：不要借用别人的手机、不要开 VPN、不要在内地远程操作开户。
2. **资料前后一致**：职业、收入、用途要和后续的资金流水对得上。
3. **别做「过桥户」**：频繁大额进出、快进快出、给陌生人收付款，是港卡被冻结的头号原因。
4. **不要出租 / 出售账户**：这可能触犯香港《有组织及严重罪行条例》，后果很严重。
5. **注意新收费**：2026-11-01 起 SWIFT 汇出每笔 HK$70，不是 Perks 会员的话，尽量用 FPS 或行内转账。
6. **奖励券记得用**：迎新券 30 天就过期，各券的门槛要提前看清。
7. **存款保障**：众安是香港存款保障计划成员，每名存款人保障上限 HK$80 万（结构性产品、股票、基金不在保障范围内）。
