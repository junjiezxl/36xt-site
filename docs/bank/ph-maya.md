Maya 是菲律宾央行（BSP）全牌照监管的数字银行巨头（相当于“菲律宾版支付宝 + 正规商业银行”）。它不仅**支持中国护照远程升级实名（KYC）**，还免费派发**全币种虚拟 Visa 或 Mastercard 借记卡**，更能一键导出带个人姓名和地址的**官方银行对账单（Bank Statement）**，成为申请其他海外机构时极佳的海外地址证明！

## 二、 开户前准备清单

- [x] **菲律宾手机号**：首推已激活的 **[DITO 手机卡/eSIM](/sim/ph-dito)**（接码完全免费，且保号成本每年不足 1 元）；
- [x] **有效证件**：有效期 > 6 个月的**因私普通护照**（用于高级实名认证与活体人脸识别）；
- [x] **网络环境（⚠️ 核心避坑！）**：
  - **切勿使用美国 IP 注册或登录！** 实测若挂美国节点，系统会自动隐藏 **Savings（储蓄）** 功能，导致无法申请虚拟卡和导出银行证明；
  - 建议使用香港、新加坡、菲律宾原生节点或直连网络；
- [x] **下载客户端**：苹果手机需使用外区（美区/港区/菲区）Apple ID 搜索下载 **Maya**；安卓手机在 Google Play 商店下载。

## 三、 手机端注册与中国护照实名升级（保姆级步骤）

### 步骤 1：基础账号注册
1. 打开 **Maya App**，允许通知和地理位置权限（必须开启定位）；
2. 点击 **Start an account**，输入你的菲律宾手机号（格式：`+63 9xxxxxxxx`）；
3. 接收并输入短信验证码，设置你的登录密码；
4. 填写姓名拼音与电子邮箱（如有邀请码可填入领取新户奖励）。

### 步骤 2：发起账户升级（Upgrade Account）
基础账户只能存放小额零钱且无虚拟卡，必须点击首页的 **Upgrade Your Account（升级账户）** 进行护照实名：

1. **选择证件类型**：在 ID Type 下拉列表中务必选择 **Foreign Passport（外国护照）**；
2. **护照与自拍上传**：
   - 清晰拍摄中国护照个人信息页（四角完整、无反光遮挡）；
   - 按屏幕提示完成**活体人脸识别检测（Liveness Detection）**，按要求眨眼或转头；
3. **关键地址填写规范**：
   - **Current Address（现住址）**：要求填写菲律宾地址。打开 Google 地图，在马尼拉（Manila）搜索任意一家正规酒店或公寓，将酒店名称、街道门牌、城市、省份及 4 位邮编完整复制填入；
   - **Permanent Address（永久住址）**：可如实填写你的中国身份证常住地址拼音；
   - **税务身份调查（US Person）**：问及是否为美国公民或美国税务居民，一律选择 **No**；
4. **提交等待审核**：资料提交后，通常在 **几分钟到 24 小时内** 自动完成审核。通过后，App 首页名字旁边会出现**绿色的已验证勾选标记（Verified）**！

## 四、 激活并查看你的虚拟卡（Virtual Card）

1. 实名升级成功后，在 App 首页点击开通 **Savings（储蓄账户）** 功能；
2. 切换到底部导航栏的 **Cards（卡片）** 页面；
3. 点击 **Claim your Free Virtual Card（领取免费虚拟卡）**；
4. 系统会立即派发一张 **Visa 或 Mastercard 虚拟借记卡**，点击卡片即可查看 **16 位完整卡号、到期月份/年份（MM/YY）及 3 位 CVV 安全码**；
5. 日常使用前，先往账户充值，即可直接绑定到各类海外网站和 App 中扣款消费！

## 五、 如何往 Maya 充值入金？（4 种正规途径）

由于新账户余额为 0，初次消费前需充入少许菲律宾比索（PHP）：

1. **Wise 跨境转账（最推荐）**：
   - 打开 Wise，选择转出英镑/美元/港币/欧元，收款币种选择 **菲律宾比索（PHP）**；
   - 收款方式选择“菲律宾电子钱包（Mobile Wallet）/ Maya”或输入你的 Maya 手机号，几分钟内秒到账，汇率极好！
2. **熊猫速汇（Panda Remit）**：支持从中国大陆或海外直接汇款到菲律宾本地电子钱包；
3. **加密货币变现通道**：Maya App 内部原生集成了 **Crypto 功能**，支持在合规场景下进行加密资产转账与比索兑换；
4. **境外信用卡/借记卡充值**：部分支持跨境线上刷卡的 Visa/Mastercard 亦可在 App 内通过 Cash In 充值。

## 六、 进阶技巧：如何开具官方「英文地址证明」？

很多朋友想开其他欧美金融平台时卡在“没有纯英文地址账单”，Maya 提供了一个绝妙的解决方案：
1. 账户升级成功后，往 Savings 储蓄账户内存入任意一笔小额资金（产生一笔流水）；
2. 在 **Savings** 页面右上角点击齿轮或更多选项，选择 **Request Bank Statement（申请银行流水对账单）**；
3. 系统会在 1 分钟内自动生成一份带 Maya 银行官方印章的 **PDF 英文对账单**并发送到你的邮箱；
4. 打开该文件，上面工工整整印有：**你的姓名拼音 + 英文街道地址 + 银行流水明细 + 银行公章**，这份高公信力文件是申请各类海外平台极好的辅助材料！
