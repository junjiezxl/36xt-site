# 恒生银行「内地先提交、90 天内赴港 App 激活」全流程（2026-11 核实版）

继汇丰之后，恒生银行也开放了同样的玩法：**持往来港澳通行证 + 内地身份证，人在内地就能用恒生 Mobile App 提交开户资料，之后 90 天内本人到香港，在 App 里上传出入境记录、完成身份认证即可开户，不用去分行排队。** 开的是「优进理财」综合户口，据官方**不设低额结存服务费**，不用压资金。

::: tip 同一趟顺手开众安
到港激活恒生只要十来分钟，建议同一趟连香港网络把众安银行（ZA Bank）也开了：众安免管理费、可绑 AlipayHK / WeChat Pay HK，开户时填邀请码 **CJV889**。流程见 [众安银行开户攻略](/bank/za-bank)。
:::

::: warning 先说清楚
内地提交 ≠ 开好户，也 ≠ 免赴港。据官方，**预先提交资料不等于已开立户口**，**90 天内必须本人到香港**并连香港本地网络完成最后一步，否则申请作废。先定好赴港行程再提交。
:::

## 一、 核心信息一览

| 项目 | 内容 | 核实情况 |
| :--- | :--- | :--- |
| **适用人群** | 年满 18 岁，持**有效往来港澳通行证 + 内地居民身份证**的内地居民 | 据官方 |
| **内地能做什么** | 在恒生 Mobile App「手机开户」→「我要开立恒生综合户口」填写并提交资料 | 据官方 |
| **激活期限** | 提交后 **90 天内**抵港，在 App 上传出入境记录 + 身份认证完成开户，**无需去分行** | 据官方 |
| **账户类型** | 优进理财（Preferred Banking）综合户口 | 据官方 + 多名网友实测 |
| **管理费** | 优进理财**无全面理财总值要求、不收低额结存服务费** | 据官方 |
| **开户后多久能转账** | 开户后可即时存款；转账、提款等全面服务约 **2–3 个工作日**后生效 | 据官方 |
| **扣账卡** | 开户成功后 5 个工作日内寄出 | 据官方；寄到内地地址还是需另行安排，**待验证** |
| **补件** | 部分情况银行会要求本人到分行补交证明文件 | 据官方 |
| **住址证明** | 只开储蓄户口一般不用；**开投资（证券/基金）户口时需要** | 据官方 |

::: info 「首 6 个月免月费体验」说的是哪个户口？
近期不少帖子说「恒生也有首 6 个月免月费体验」。据官方，**首 6 个月豁免低额结存服务费的是「优越理财（Prestige）」**，期满后上月全面理财总值低于 100 万港币要收月费（50 万–100 万每月 40 港币，低于 50 万每月 340 港币）。**普通人开优进理财就够了，本来就不收月费**，别被引导升级。
:::

## 二、 办理前准备材料

- [x] **往来港澳通行证**：有效，带芯片（App 要用 NFC 读取）
- [x] **内地居民身份证**：拍照核验
- [x] **带 NFC 的手机**：多名网友反馈 iPhone 读通行证芯片要反复调整位置，有人试了几十次才成功、换安卓一次通过（网友经验，**非官方说法**）。有备用安卓机的带上
- [x] **能收短信的手机号**：提交后参考编号会发短信，务必保存
- [x] **出入境记录**：到港后用微信小程序「移民局 12367」或「国家政务服务平台」下载电子版 PDF（过关后通常要等十几分钟才查得到）
- [x] **住址信息**：据官方，自 2026-09-29 起海外/跨域转账要求你的住宅地址包含「市镇／城市」，开户时就把城市填完整，省得以后转账被卡
- [x] **住址证明（可选）**：要开证券/基金户口时准备，内地居民可用近 3 个月的公用事业账单、手机/宽带月结单，或户口簿/居住证

## 三、 第一阶段：人在内地提交资料（约 15 分钟）

1. 下载**恒生 Mobile App**（香港版），打开后在「快速连结」选择 **「手机开户」**。
2. 选择 **「我要开立恒生综合户口」**，账户选优进理财。
3. 按提示**拍摄往来港澳通行证** → 用 **NFC 读取通行证芯片** → **自拍**做人脸核验。
4. 填写个人资料：职业、收入、开户目的、内地住址（写全省/市/区，**城市一栏别漏**）。资料照实填，和后面要提供的材料对得上。
5. 提交后保存短信里的**申请参考编号**。找不到短信可以打恒生开户查询电话找回（号码在 App 和官方页面里）。

::: tip 关于推荐编号
据官方，2026-10-01 至 2026-12-31 有「亲友推荐赏」：受荐人开优进理财、登记 e-Banking、开户当月存入 1 万港币以上并维持到开户月后第四个月，**受荐人可得 200 港币现金**。网上流传的「400 港币」**说法不一**——官方页面上 400 港币是推荐转用 PayDay+ 出粮户口的奖赏；而且官方条款写明推荐赏不能和其他优进理财手机开户优惠叠加，部分优惠条款还注明「仅适用于身处香港的人士」。想拿奖励的，以 App 和官方条款为准，**不要为了奖励压一万港币不动**。
:::

## 四、 第二阶段：90 天内到香港，App 完成开户（约 10 分钟）

1. 过关后先**下载本次入境的出入境记录 PDF**。
2. 连**香港本地网络**（香港手机卡、漫游或可靠的 Wi-Fi；高铁站免费 Wi-Fi 有次数限制，有网友中途被断）。
3. 打开恒生 Mobile App →「手机开户」→ 找回刚才提交的申请，**上传出入境记录**并按提示**完成身份认证**。
4. 收到开户成功短信后，立即**登记个人 e-Banking**（设置用户名和密码，务必记下来）。
5. 趁还在香港，**顺手开众安银行**：开户时填邀请码 **CJV889**，十分钟左右搞定，两张卡互为备份。

## 五、 开户后必做设置

::: warning 首笔入金风控（2026-11 网友反馈，待验证）
近两日有多名网友提到：恒生开户过程顺利，但**第一笔汇入后被追问补资料，甚至要本人再去分行**。这不是官方新规，个案成分居多，建议首笔用**小额同名转入**测试，并预留时间应对补件，不要一开完就大额快进快出。
:::

::: warning 拿到账户后第一件事
1. **设好转账限额**：要转去内地或海外，先在 App 里设「内地及海外每日转账限额」，否则 Global Money+ 用不了。
2. **头几天别急着大额转出**：据官方，转账、提款约 2–3 个工作日后才开放；有网友反馈新户前几天额度较低。
3. **小额首笔入金**：先从自己的同名港卡（如众安）用 FPS 转入一小笔测试，再按需入金。首笔入金思路见 [首笔入金与激活避坑](/bank/first-deposit)。
4. **记好登录名和户口号码**：恒生和汇丰一样，忘了登录名要走找回流程，很麻烦。
:::

## 六、 恒生值得用的几个功能（据官方收费）

| 场景 | 费用 / 规则 |
| :--- | :--- |
| **Global Money+ 汇往指定 50 多个国家/地区（当地货币）** | 手续费 **0**（如美元汇美国、英镑汇英国）；收款行/中转行仍可能另收费 |
| **Global Money+ 非当地货币或非指定地区** | 每笔 **160 港币**（含海外银行收费） |
| **汇往中国内地** | Global Money+ **手续费 0**；经网站 65 港币；分行 190/230 港币（均不含海外银行费用） |
| **人民币汇往内地同名账户** | 受人民币跨境规定限制，**每日上限 8 万元人民币** |
| **每日转账上限** | 未登记收款人 40 万港币；已登记收款人 150 万港币 |
| **海外汇入恒生** | 据官方免手续费 |

::: tip 入金美国券商
网上常说「恒生 Global Money+ 0 手续费入金嘉信」。据官方，**以美元汇美国属于免手续费范围**，但官方也注明汇往美国的费用会视收款人资料而定，**提交前 App 会显示实际费用**，以那一页为准。详细做法见 [港户入金嘉信与美股资金回流](/bank/schwab-funding)。
:::

## 七、 常见问题

| 问题 | 答案 | 来源 |
| :--- | :--- | :--- |
| 内地提交后就不用去香港了？ | ❌ 不是，90 天内必须本人到港完成 | 官方 |
| 要不要压 1 万港币？ | 优进理财不收月费，**不用压**；只有想拿推荐/开户奖励才需存够 1 万并维持 | 官方 |
| 和「内地见证开户」有什么区别？ | 见证开户在广州、深圳、北京、上海的恒生中国指定分行办，不用来港；资产门槛等要求以分行答复为准（网传 50 万人民币、存满 3 个月，**待验证**）。详见 [恒生银行（免赴港见证）](/bank/hangseng-bank) | 官方 + 网友 |
| 汇丰和恒生只能二选一？ | 网上有这种说法，**官方未见此限制**，多名网友两家都开成功 | 网友实测 |
| 只开储蓄户口要去分行面签吗？ | 一般不用；银行要求补件时才去 | 官方 |
| 恒生和汇丰怎么选？ | 汇丰 One 新户月均总值不到 1 万港币每月收 100 港币管理费；恒生优进理财不收。不想压资金先开恒生 | 官方 + [汇丰内地预申请攻略](/bank/hk-hsbc-remote) |
