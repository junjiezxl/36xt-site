## 先说结论

**iFAST Global Bank（奕丰环球银行）** 是一家英国持牌数字银行。据官方首页：由英国审慎监管局（PRA）授权，并受 PRA 与金融行为监管局（FCA）监管；合资格存款受英国金融服务补偿计划（FSCS）保障，上限 **£120,000**（该上限自 2025-12-01 由 £85,000 上调）；**开户免费、无年费、无开户设置费、无最低余额要求**；一个多币种活期账户可使用 **英镑、美元、欧元、港币、新加坡元、人民币、日元、瑞士法郎、阿联酋迪拉姆、加拿大元、澳大利亚元** 共 11 种货币（官方首页表述为 CNY；账户内实际清算币种是否为离岸人民币，**待以 App 为准**）。

它适合作为**第二层英国银行账户、多币种备份**，而不是 Wise 的替代品，更不替代香港银行卡。对内地用户来说，更稳妥的组合通常是：港卡做主通道，Wise 做常用收款与换汇，iFAST 做英国持牌银行备份。不要把全部资金押在单一账户上。

开户可以远程申请，但**获批不是保证**。申请表必须如实、完整、前后一致。不要为了“好过审”改搬入时间、隐瞒资产情况，或把资金来源地、转出地改成不属实的国家。

## 一、它是什么，监管怎么看

- **牌照与监管**：据官方，这是英国持牌银行，PRA 授权，PRA 与 FCA 监管。它不是EMI 电子货币机构，和只持有支付牌照的平台不是同一类。
- **存款保障**：据官方，合资格存款受 FSCS 保障，上限 £120,000（每人每家持牌机构，以 FSCS 当时规则为准）。这是法定补偿计划，不是银行自己的营销承诺。
- **费用底线**：据官方首页，开户免费、无年费。据 2025-03-27 生效的官方费用信息文件，**账户维护费为 0**；英国更快支付（Faster Payments）收款、汇款均为 0。更细的跨境电汇费用见下文「费用要点」。
- **适用对象**：官网面向个人客户提供多币种活期账户，并展示国际汇款能力。是否对所有居住地、所有证件类型都开放，**以你打开申请页时的可选项为准**，官方首页并未逐条列出「保证中国大陆居民一定获批」。

多家近期教程和本站既有整理均提到：大陆用户可尝试用**护照 + 身份证 + 大陆居住地址证明**远程申请。这与当前申请页的常见选项相符，但**可申请不等于必获批**。

## 二、适合谁，不适合谁

![iFAST 在账户组合里的位置：Wise 做常用收款换汇，iFAST 做英国银行备份，港卡做跨境主通道](/images/ifast/ifast-positioning.png)

**比较适合：**

- 已经有或准备办理港卡，希望再备一个英国持牌银行账户做备份；
- 需要英镑本地收款，或一个账户里同时放多种常用外币；
- 希望账户维护费为 0、没有最低余额压力；
- 能提供真实、一致的身份与地址材料，并接受审核时间不确定。

**不太适合 / 需要先降低预期：**

- 想把它当作「出金跳板」、加密货币交易所中转，或绑定各种 U 卡进出——本站**不建议**这类路径，也容易触发风控；
- 指望用它完全替代港卡，处理与内地之间的日常收付款；
- 材料造假、地址不符，或无法说明资金来源与用途；
- 把大额资金长期只放在这一家，忽视分散与合规申报。

近期有用户反馈部分多币种账户（例如 Wise）出现关户或资金暂时取不出的情况，个案原因**待验证**。更稳妥的做法是：常用归常用，备份归备份，大额不要长期集中在单一非港卡通道。详见 [《首笔入金与激活避坑》](/bank/first-deposit)。

## 三、开户前要准备什么

![远程开户材料清单：护照、大陆身份证、居住地址证明、适合人脸识别的环境和网络](/images/ifast/ifast-materials.png)

建议一次性备齐再提交：

1. **有效护照**：在有效期内，整页清晰，边角完整，避免反光和遮挡。
2. **大陆身份证**：多家近期申请页仍将其列为可接受的身份证明之一，以你提交时页面可选证件为准。
3. **居住地址证明**：官方公开首页没有单独列出一份完整的「地址证明合格标准」。据多方对申请页的整理，通常要求文件上有**完整姓名、当前居住地址、近 3 个月内的日期**；建议上传**完整 PDF**，不要用截图或缺页照片。常见来源包括银行或信用卡月结单、水电燃气账单、政府部门信函。填写的居住地址必须与证明文件**完全一致**，不要自行简称或改写。具体怎么开，见 [《零成本地址证明攻略》](/roadmap/address-proof)。细则请以申请页当时提示为准。
4. **稳定网络和安静、光线均匀的环境**：全程需要人脸识别，建议用手机一次拍清，避免反复失败。

手机号方面，近期用户反馈可使用 `+86` 号码接收验证码（网友共识，**待你在申请页复核**）。电子邮箱建议用本人常用、能长期登录的邮箱，后续对账单和风控问询都会发到这里。

## 四、开户流程：务必如实填写

![六步远程开户：进官方申请页、填个人信息、回答合规问卷、上传材料、人脸识别、等待审核](/images/ifast/ifast-process.png)

流程示意如下，**具体步骤以官方申请页为准**：

1. **只从官方网站进入申请。** 不要通过来路不明的分享页，也不要使用带推荐参数的第三方链接提交。
2. **填写个人信息。** 中英文姓名、出生日期、证件号码、联系方式与证件完全一致。居住地址按地址证明原文填写。
3. **回答合规问卷。** 职业、收入来源、是否持有加密资产、资金来源地和转出地，一律按**真实情况**填写，并与你后续的入金、出金口径保持一致。
4. **上传护照、身份证和地址证明。** 按页面格式要求提交完整文件。文件模糊、截图、姓名地址不一致，是常见的退回原因。
5. **完成人脸识别。** 按提示眨眼或转头；避开逆光、墨镜、口罩和镜头抖动。
6. **等待审核，通过后设置登录方式，查看账户明细。** 第一笔入金请用本人同名合规银行账户小额试水。

审核时长**没有统一的官方承诺**。网友反馈短则数小时，常见一到两个工作日，也有一周或更久。以审核结果为准，不要在等待期间反复重复提交。

::: danger 申请表必须说真话
有些流传教程会教人「为了好过审」去改答案，例如把搬入时间改成更长、在加密资产问题上选「没有」，或把资金来源地、转出地填成并不符合事实的国家。**这些做法不要学。**

银行做的是尽职调查，不是看谁把表格填得「更像本地居民」。虚假或前后矛盾的申报，轻则拒批、补件，重则开户后被限制或关户，也有合规风险。搬入时间、资产情况、资金从哪里来、准备转到哪里去，都按事实填写，并保证和地址证明、后续流水对得上。
:::

部分教程提到申请过程中会有中文提示或简单的视频确认题。界面语言、是否出现视频问卷，**以你当时看到的页面为准（待验证）**。若出现问题，如实简要说明开户用途（例如个人合法储蓄、经常项目下的跨境消费与资金调拨），不要背诵与自身情况不符的「标准答案」。

## 五、开好以后怎么看账号、怎么用

通过后，先在账户页核对户名是否为你本人姓名，再保存收款信息。使用前建议分清两类明细（此为社区和申请后账户页的常见分类，**本次未在官方公开首页找到逐条说明，待以 App 显示为准**）：

- **英国境内收款信息**：多用于英镑本地更快支付，通常是 Sort Code 与账号。
- **国际收款信息**：用于跨境电汇或多币种汇入，通常会提供 IBAN、BIC/SWIFT 以及相应币种的收款细节。

汇款前务必按**收款币种**选择对应明细，先小额测试，确认户名、账号、币种都正确后再增加金额。用错「境内 / 国际」明细，是网上较常见的退汇或延迟原因。

关于绑定 PayPal：有第三方教程称可以用 iFAST 的英国账号绑定英国 PayPal，或向 PayPal 的英镑账户转账。**本次未在官方页面确认，待验证**，不作为可以办成的承诺。即使有人实测成功，规则也可能调整。

官方首页展示了 Visa 借记卡的产品示意图。实体卡或虚拟卡是否对远程新户开放、年费、邮寄地区和申请条件，**本次未在官方费用文件中逐条核对，待以账户内申请页为准**。没有卡，也不影响先把同名多币种账户作为备份来用。

账户开出来以后，建议保留合理的登录和小额活动记录，避免长期完全不动，或突然出现与申请时声明完全不符的大额、高频进出。

## 七、入金、出金与合规提醒

![入金路径对比：建议走同名港卡或 Wise，不建议走加密货币交易所或 U 卡](/images/ifast/ifast-funding.png)

### 建议走的路：本人同名银行通道

- **香港银行卡**（如众安、蚂蚁银行澳门、汇丰、渣打等）同名汇入，是内地用户最常见、也最好解释的路径之一。港卡怎么开，见 [香港银行卡开户](/bank/) 与 [《香港三卡组合怎么配》](/bank/hk-three-card)。
- **Wise 等本人名下、状态正常的多币种账户**转入。英镑走英国更快支付，多位用户反馈费用低、到账快；请先确认该账户本身可以正常汇出。
- 若暂时没有其他境外账户，可用**内地银行本人账户合规购汇后同名电汇**做小额测试。务必按外汇管理规定如实申报用途，并注意年度额度（见下）。
- 第一笔建议小额，核对户名、账号、币种后再增加金额。首笔必须同名、金额是否不设下限，是网友较一致的说法，**请以 App 入金页提示为准**。更细的路径对比见 [《首笔入金与激活避坑》](/bank/first-deposit)。

### 不建议走的路：加密资产与 U 卡

本站**不建议**把 iFAST 当成加密货币出金通道，也不建议走「交易所 → 其他平台 → iFAST」或 U 卡中转。这类路径资金来源更难向银行解释，也更容易触发风控。

据 2024 年 9 月前后银行客户邮件的公开转述，**自 2024-10-01 起，向外支付到与加密资产相关的账户不再被允许**。是否仍接受来自英国 FCA 注册或同等监管平台的入金，外界口径并不完全一致。出金到交易所或 U 卡，多方反馈为不支持。以上政策**待以官方 FAQ 或客户通知原文复核**。对普通用户而言，结论很简单：进出都走同名银行账户。

来源不明的资金、第三人代付、故意拆分掩饰资金性质，都可能被拒绝、退回或导致限制使用。

### 外汇额度与 CRS

- 境内个人年度便利化购汇额度为等值 **5 万美元**（按自然年计算），须用于经常项目等已开放用途；**不得用于境外买房、证券投资、投资性返还分红保险等未开放的资本项目**。购汇和对外付款时如实申报用途，不要为规避审核而拆分交易或虚构用途。
- 英国金融机构会按共同申报准则（CRS）等规则，与税务居民所在地交换账户信息。请按**真实税务居民身份**申报，保持与身份证、护照和银行资料一致。这是正常的跨境税务信息交换安排，不是「开了海外账户就可以隐瞒收入」。
- 更完整的资金路径说明，见 [《跨境资金闭环（合规版）》](/roadmap/compliant-fund-loop)。

## 八、避坑清单

![七个常见坑：假信息、地址不符、人脸识别失败、汇错账户明细、加密路径、忽略费用、资金过度集中](/images/ifast/ifast-pitfalls.png)

1. **申请表不要写假信息。** 搬入时间、加密资产、资金来源地和转出地必须属实，并与后续流水一致。
2. **地址必须与证明完全一致。** 门牌、小区、省市不要简写或错位；证明建议近期、带全名，优先完整 PDF。
3. **人脸识别一次拍清。** 反复失败可能延长审核，或被要求重提材料。
4. **认准账户明细再汇款。** 「英国境内」与「国际」信息可能不同，以 App 为准，先小额测试。
5. **不要用加密路径进出。** 不要把这个账户设计成交易所或 U 卡的跳板。
6. **汇出前先看官方费用。** 本地更快支付通常免费；SWIFT 汇出按币种定额，中间行还可能另扣。
7. **不要把鸡蛋放进一个篮子。** iFAST 适合备份，不替代港卡；留合理活动记录，避免长期完全不动或异常进出。

另外，网上如果出现「内部渠道费」「代做地址证明」「保证过审」的中介，直接忽略。远程开户没有需要向第三方付开通费的官方流程。
