## 四、 激活后必做设置（防扣费与保号）

::: warning 拿到卡后第一件事
1. **立即关闭该卡的数据漫游**：避免后台 App 自动走境外流量扣光话费。
2. **关闭呼叫转移/语音信箱**：防止陌生骚扰电话因无人接听转入语音信箱扣费。
3. **设置保号闹钟**：在手机自带日历中新建一个 **每 150 天重复一次** 的提醒，定时产生一次小额变动。
:::
